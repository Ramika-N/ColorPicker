# C# Screen Color Picker (Eyedropper)

A lightweight desktop utility built with C# Windows Forms to pick color codes directly from any pixel on the screen.

## Features
- **Real-time Magnifier:** Zoomed view around cursor with crosshair target.
- **HEX Conversion:** Continuous RGB-to-HEX color string conversion.
- **Auto-Copy:** One-click copy to system clipboard.
- **TopMost Window:** Stays on top for easy accessibility during UI design.
