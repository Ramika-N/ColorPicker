# C# Screen Color Picker (Eyedropper)

A lightweight desktop utility built with C# Windows Forms to pick color codes directly from any pixel on the screen.

* **Screen Eyedropper:** Pick color codes from any location on your desktop in real-time.
* **Color Formats:** Supports common formats including HEX, RGB, and HSL.
* **Clipboard Integration:** Instantly copy generated color codes with a single click.
* **Lightweight & Fast:** Minimal memory footprint with quick launch support.
